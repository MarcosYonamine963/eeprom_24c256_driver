# EEPROM 24C256(N) Driver

Driver for EEPPROM 24C256N memory.

## Instalation

At your repository, use git submodule:

* Go to Git Bash, enter your repo at the directory where you want to place the driver folder, and run the commannd:

      git submodule add git@github.com:MarcosYonamine963/eeprom_24c256_driver.git ./eeprom_24c25_driver


* To inicialize the submodule:

      git submodule init
